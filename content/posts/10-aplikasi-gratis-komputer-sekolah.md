Banyak sekolah masih pakai software bajakan karena merasa software asli terlalu mahal. Padahal ada banyak aplikasi gratis (open source) yang kualitasnya setara — bahkan lebih baik — dari versi berbayar.

Berikut 10 aplikasi gratis yang wajib dipasang di komputer sekolah.

## 1. LibreOffice — Pengganti Microsoft Office

- **Fungsi:** Word, Excel, PowerPoint gratis
- **Kelebihan:** bisa buka dan simpan format .docx, .xlsx, .pptx (kompatibel dengan Microsoft Office)
- **Download:** libreoffice.org

## 2. GIMP — Pengganti Adobe Photoshop

- **Fungsi:** edit foto, buat poster, desain
- **Kelebihan:** fitur lengkap, cocok untuk bikin poster kegiatan sekolah
- **Download:** gimp.org

## 3. Inkscape — Pengganti Adobe Illustrator

- **Fungsi:** desain vektor, logo, brosur
- **Kelebihan:** cocok untuk bikin logo sekolah, brosur PPDB
- **Download:** inkscape.org

## 4. OBS Studio — Rekam Layar & Live Streaming

- **Fungsi:** rekam layar komputer, streaming
- **Kelebihan:** gratis, cocok untuk bikin video pembelajaran
- **Download:** obsproject.com

## 5. Audacity — Edit Audio

- **Fungsi:** rekam dan edit audio
- **Kelebihan:** cocok untuk podcast edukasi atau materi audio
- **Download:** audacityteam.org

## 6. PDF24 Creator — Edit PDF

- **Fungsi:** gabung, pisah, kompres PDF
- **Kelebihan:** gratis tanpa watermark, cocok untuk administrasi
- **Download:** pdf24.org

## 7. Foxit Reader — Baca PDF Ringan

- **Fungsi:** baca PDF
- **Kelebihan:** lebih ringan dari Adobe Reader, cepat di komputer lama
- **Download:** foxit.com

## 8. 7-Zip — Kompres File

- **Fungsi:** zip/unzip file
- **Kelebihan:** gratis, lebih cepat dari WinRAR, tidak ada popup iklan
- **Download:** 7-zip.org

## 9. Mozilla Firefox — Browser Aman

- **Fungsi:** browser internet
- **Kelebihan:** privasi lebih baik dari Chrome, bisa pasang ekstensi blokir iklan
- **Download:** mozilla.org

## 10. VS Code — Editor Teks Ringan

- **Fungsi:** editor teks untuk coding atau nulis
- **Kelebihan:** gratis, ringan, banyak ekstensi
- **Download:** code.visualstudio.com

## Cara Pasang Semua Sekaligus

Untuk memasang semua aplikasi sekaligus tanpa buka website satu-satu, gunakan **Ninite** (ninite.com):

1. Buka ninite.com
2. Centang aplikasi yang ingin dipasang
3. Klik "Get Installer"
4. Jalankan file yang didownload — semua aplikasi terpasang otomatis
